# 🚀 Быстрый старт - Полностью автоматический анализ

## 📋 Шаг 1: Установка зависимостей

```bash
pip install -r requirements.txt
```

## 🔑 Шаг 2: Получить API ключ (БЕСПЛАТНО)

### API-Football.com - 100 запросов/день бесплатно

1. Перейди на https://www.api-football.com/
2. Нажми "Get Your Free API Key"
3. Зарегистрируйся (email + пароль)
4. Подтверди email
5. Зайди в Dashboard → API Key
6. Скопируй свой ключ

**Бесплатный план:**
- 100 запросов/день
- Все лиги
- Коэффициенты от всех букмекеров
- Форма команд, травмы, таблица, H2H
- Этого хватит для анализа 5-10 матчей в день

## ⚡ Шаг 3: Запуск автоматического анализа

### Вариант A: Командная строка

```bash
python auto_analyzer.py \
  --api-key ВАШ_API_КЛЮЧ \
  --home "Manchester City" \
  --away "Liverpool" \
  --league EPL
```

### Вариант B: Python скрипт

```python
from auto_analyzer import FullyAutomatedAnalyzer

# Инициализация
analyzer = FullyAutomatedAnalyzer(api_key='ваш_ключ')

# Автоматический анализ
result = analyzer.analyze_match(
    home_team="Manchester City",
    away_team="Liverpool",
    league='EPL',
    use_elo=True
)
```

## 🎯 Что происходит автоматически

1. ✅ **Поиск матча** - находит предстоящий матч в лиге
2. ✅ **Коэффициенты** - получает актуальные коэффициенты от букмекеров
3. ✅ **Форма команд** - последние 5-10 результатов
4. ✅ **xG данные** - детальная статистика из Understat
5. ✅ **Травмы** - список травмированных игроков
6. ✅ **H2H** - статистика личных встреч
7. ✅ **Таблица** - место команд в турнирной таблице
8. ✅ **Корректировка** - учет формы, травм, мотивации
9. ✅ **Прогноз** - математическая модель (Пуассон + ELO)
10. ✅ **Value ставки** - поиск выгодных коэффициентов
11. ✅ **Kelly criterion** - оптимальный размер ставки

## 📈 Batch-анализ (несколько матчей)

```python
from auto_analyzer import FullyAutomatedAnalyzer

analyzer = FullyAutomatedAnalyzer(api_key='YOUR_KEY')

matches = [
    ("Manchester City", "Liverpool"),
    ("Arsenal", "Chelsea"),
    ("Tottenham", "Manchester United")
]

for home, away in matches:
    result = analyzer.analyze_match(home, away, league='EPL')
    # Результаты сохраняются автоматически
```

## 🐛 Troubleshooting

### Ошибка "Invalid API key"
Проверь, что скопировал ключ правильно (без пробелов)

### Ошибка "Team not found"
Используй точное название команды из API:
- ✅ "Manchester City"
- ❌ "Man City"
- ❌ "ManCity"

### Ошибка "Fixture not found"
Матч еще не добавлен в расписание или уже сыгран. Проверь дату.

### Ошибка "Rate limit exceeded"
Превышен лимит 100 запросов/день. Подожди до завтра или апгрейдься.
